# PWM-Based Vacuum Control Notes

## Objective

Control the KMDP 24V diaphragm pump using PWM generated by the Raspberry Pi Pico 2W.

---

## Hypothesis

Increasing the PWM duty cycle increases the average motor speed, thereby increasing the generated chamber vacuum.

The BMP280 pressure sensor provides feedback, allowing the controller to adjust PWM to maintain a desired vacuum setpoint.

---

## Proposed Control Architecture

```text
Setpoint Vacuum
       │
       ▼
 PI / PID Controller
       │
       ▼
   PWM Duty Cycle
       │
       ▼
   L298N Driver
       │
       ▼
 KMDP 24V Pump
       │
       ▼
 Pneumatic Chamber
       │
       ▼
    BMP280
       │
       └────── Feedback ──────►
```

---

## Expected Relationship

| PWM Duty | Expected Vacuum |
|-----------|----------------|
| 0% | Pump OFF |
| 20-40% | Low suction |
| 40-70% | Moderate suction |
| 70-90% | High suction |
| 100% | Maximum suction |
